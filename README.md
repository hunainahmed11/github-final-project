# Simple Interest Calculater

A small Bash command-line calculator that computes simple interest from a principal amount, an annual interest rate, and a time period in years.

## Purpose

This project demonstrates a simple financial formula and provides a readable example of collecting and validating user input in a Bash script.

## Formula

**Simple Interest = (Principal × Rate × Time) / 100**

- **Principal (P):** the initial amount of money.
- **Rate (R):** the annual interest rate, expressed as a percentage.
- **Time (T):** the duration of the investment or loan, in years.

## Usage

From a terminal with Bash installed, run:

```bash
bash simple-interest.sh
```

Enter the principal, annual rate, and time period when prompted. For example, a principal of `1000`, a rate of `5`, and a time of `2` years produces simple interest of `100.00`.
